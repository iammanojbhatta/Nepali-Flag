# 🇳🇵 Nepali-Flag — The Flag of Nepal in HTML & CSS

The world's only non-rectangular national flag — **Nepal's flag**, presented as a web page with HTML and CSS.

## Open it
Open `index.html` in any browser.

## Inside
- `index.html` — the page
- `style.css` — the styling
- `flag of Nepal .png` — the flag artwork

A small patriotic front-end practice project. Jay Nepal! 🇳🇵
